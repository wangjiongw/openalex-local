# 查询覆盖与限制

[English](API-COVERAGE.md) · [文档导航](INDEX.zh-CN.md)

默认元数据 profile 提供源记录和引用关系。文本索引可选，当前内置示例为地球科学。

在自己的运行服务上读取 `/capabilities` 和 `/status`，确认支持的过滤条件、已索引实体、
已发布范围与 generation。`/docs` 提供可交互的路由说明。
官方风格路由不代表完整兼容官方 API。

| 查询 | 本地实现 | 覆盖边界 |
| --- | --- | --- |
| DOI／OpenAlex ID | 完整源记录查询，显式返回 DOI 歧义 | 已导入元数据，与文本索引独立 |
| 标题／摘要／关键词 | Manticore 词法全文字段 | 仅已发布论文索引；首个 profile 为广义地学 |
| 论文中的作者姓名 | 作者姓名文本搜索与论文过滤 | 已发布范围内的论文 |
| Topic／来源名称 | 独立名称索引和 ID 过滤 | 仅该 build 包含的实体，其他目录可能尚未构建 |
| 作者／机构名称 | 可选且经过验收的目录，包含别名和关联文献入口 | 示例中为地学关联作者及全部已导入机构；标识符仍可解析已导入元数据 |
| 批量论文导出 | 查询或 DOI／ID 清单，API／CLI／网页输出 JSONL.gz、CSV 和 DOI／ID 清单 | 固定数据／索引版本，分块回执、取消／恢复；不自动下载 PDF 或展开引用目标 |
| 年份、OA、来源／Topic／作者 ID 及组合 | 已支持的索引过滤；元数据路由支持相应源字段条件 | 以 capabilities 为准，任意 JSON 条件并不都有索引 |
| 参考文献（references） | 将源 `referenced_works` 正向引用展开为记录 | 报告未解析目标，不推断补齐空源数组 |
| 被引文献（citations） | 从导入参考文献构建反向边 | 完整性受快照覆盖和时间限制 |
| 相关文献（related works） | 将源 `related_works` 展开为记录 | 不新增 embedding 或语义推荐计算 |
| 完整记录字段 | 保留源 JSON，支持字段选择 | 源信息缺失时仍然缺失 |

范围外论文如果已经导入元数据，仍能通过 DOI／ID 查询并出现在引用展开结果中，
即使它的标题不能在已发布地学索引中搜索。部分快照在发布后仍是不完整数据。
论文中的作者姓名检索与独立作者实体目录是两项能力。
预印本和正式发表记录保留各自原 ID，不自动跨记录合并。可选 [arXiv 来源](ARXIV.zh-CN.md) 增加唯一精确 DOI 关联、独立检索及发表版优先详情。

不承诺官方线上排序、实时更新、全部过滤／聚合条件、所有实体名称索引或全学科文本搜索。
Parquet 导入、实时删除／合并应用和外部 A/D 图谱写入不属于社区核心候选版。
词法文本索引不是向量索引；源参考文献缺失也不等于论文真实没有参考文献。

检索增补和导出契约见[检索与导出](SEARCH-EXPORT.zh-CN.md)。
实体名称仅在新增目录通过验收并发布后可检索；标识符查询保持对已导入数据的覆盖。

小型来源词表无需文本索引即可按名称浏览；层级选择和文献导航复用现有作品过滤。见[实体目录](DIRECTORIES.zh-CN.md)。出版商／资助方／项目名称扩展仍为 M2 后续任务。

[版本关联](VERSIONS.zh-CN.md) — `/v1/works/{id}/version-group`, `/v1/version-groups/{group_id}`; `/status.version_groups`, `/capabilities.version_groups`.
