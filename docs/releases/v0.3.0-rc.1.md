# OpenAlex Local v0.3.0-rc.1

This candidate adds reusable entity catalogs and durable result exports to the local snapshot-to-service toolchain.

- Add full institution catalogs and authors linked to the published Earth example, reusing existing work indexes.
- Export works from queries or DOI/ID lists as JSONL.gz, CSV and DOI/ID lists through HTTP, CLI and the web UI.
- Persist jobs independently of API processes, with pinned generations/builds, chunk checksums, cancellation and checkpoint recovery.
- Add author identity, institution and language controls, entity-to-works navigation, saved query URLs and result selection.
- Extend native end-to-end coverage to catalog publication, aliases and export downloads; qualify queries alongside active exports.

Start with the [deployment guide](../QUICKSTART.md) and [query/export guide](../SEARCH-EXPORT.md). Snapshot acquisition remains user-managed; Earth text indexing and its linked author catalog are optional. DOI/ID lookup and citation expansion cover imported metadata independently of text coverage.

This is a prerelease, not complete live OpenAlex API parity. It does not add all-discipline text indexes, the full author-name catalog, PDF downloads, automatic paper-version merging, semantic retrieval or snapshot synchronization. Full parent-index recovery evidence is reused; this release does not claim a new independent ClickHouse disaster-recovery exercise. Runtime datasets and private acceptance reports are not release assets.
