# OpenAlex Local v0.3.1

[English](v0.3.1.md) · [文档导航](../INDEX.zh-CN.md)

增加可选的内部免密运行方式，默认仍开启认证。
在现有 workspace 配置中将布尔值 `auth_required` 设为 false，保留密钥以便恢复。
网页无需输入密钥即可连接、查询、导出和下载；status、capabilities 与 OpenAPI 反映当前模式。

请求超时、上传限制和已配置资源控制仍生效，匿名限流计数不信任请求提供的 key。
查询语义、索引投影、引擎版本及数据布局不变化，已有索引直接复用。
配置说明见[部署指南](../QUICKSTART.zh-CN.md#可选内部免密部署)。

测试覆盖认证开启／关闭、无效设置、请求保护和导出路由。
元数据／搜索恢复证据仍仅对原执行范围成立，本补丁不新增独立数据库灾备演练。
