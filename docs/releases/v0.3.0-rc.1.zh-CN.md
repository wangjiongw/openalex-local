# OpenAlex Local v0.3.0-rc.1

[English](v0.3.0-rc.1.md) · [文档导航](../INDEX.zh-CN.md)

本候选版为本地快照到服务的工具链增加可复用实体目录及持久结果导出。

- 无需重建论文索引，增加可恢复的身份到论文候选映射，用于查询／导出预过滤。
- 增加全部已导入机构目录及已发布地学示例关联作者，复用已有论文索引。
- 查询或 DOI／ID 清单可经 HTTP、CLI、网页导出为 JSONL.gz、CSV 和 DOI／ID 列表。
- 任务独立于 API 进程持久化，固定 generation／build，含分块校验、取消与检查点恢复。
- 网页增加作者身份、机构、语言、实体关联文献、查询 URL 和结果选择。
- 原生端到端检查扩展至目录发布、别名和导出下载；查询验收与真实导出同时运行。

从[部署指南](../QUICKSTART.zh-CN.md)和[检索／导出指南](../SEARCH-EXPORT.zh-CN.md)开始。
快照仍由用户获取；地学文本索引和关联作者目录可选。
DOI／ID 查询与引用展开覆盖已导入元数据，不依赖文本范围。

这是预发布版本，不完整对齐实时 OpenAlex API。
不增加全学科文本索引、全量作者姓名目录、PDF 下载、自动论文版本合并、语义检索或快照同步。
复用父索引全量恢复证据，不声称新增独立 ClickHouse 灾备演练。
运行数据和私有验收报告不是发布附件。

验证包括跨架构单元／原生 CI、安装包流程、新目录物理／恢复检查及全量查询／导出混合负载。
实际范围与限制见[验证状态](../VALIDATION.zh-CN.md)。
