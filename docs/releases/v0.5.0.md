# v0.5.0 — conservative OpenAlex version details

[中文](v0.5.0.zh-CN.md) · [Version workflow](../VERSIONS.md)

Adds independent resumable relationship releases, replaying published arXiv exact evidence and a deterministic 100,000-record stratified Earth pilot. Conflicting publication choices and notices remain under review; repeated DOIs, links and title similarities do not automatically confirm versions. A preprint-only match never invents a publication.

New version-group API routes, optional readiness/coverage, evidence inspection, publication-first details, persistent manual selection and group JSON downloads preserve every original W ID. References, OA and citation counts remain per member. Existing arXiv `/versions`, search counts/paging and selected/query exports keep their contracts. Grouped search and grouped background export remain later work.

Qualification includes synthetic decision/conflict/replay/sample tests, native metadata/Earth integration, browser version selection/reference provenance and installed-package acceptance. Every installation independently validates its source and relationship data before publishing. This does not establish exhaustive Earth version recall, calibrated fuzzy precision, cross-Pod capacity or resolution of historical metadata checksum faults.

No work/arXiv text reindex is needed. Upgrade API and export worker together; preserve the prior environment, all source/index dependencies, relationship staging and active-pointer history. Software rollback and relationship rollback remain separate operations.
