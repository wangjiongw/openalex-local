# OpenAlex Local v0.3.0

[English](v0.3.0.md) · [文档导航](../INDEX.zh-CN.md)

基于使用者已下载 OpenAlex 快照的本地文献检索稳定版。
本版收敛已验收的 v0.3.0-rc.1 应用；查询、投影、数据布局、引擎和依赖均不变化，
只调整包／API 版本声明。兼容的现有元数据与索引可直接复用，无需重建或重新发布数据。

## 受支持流程

- 读取／校验本地 JSONL，完整保留元数据、标识符和引用边。
- 通过 HTTP 和网页查询 DOI／ID、详情、参考文献、被引文献及相关文献。
- 可选发布地学文本范围及关联作者／机构目录，支持标题、摘要、关键词、作者姓名及已支持的组合过滤。
- API／CLI／网页支持查询或 DOI／ID 清单导出为 JSONL.gz／CSV／DOI／ID，提供持久任务、取消、恢复和带认证下载。

入口见[部署](../QUICKSTART.zh-CN.md)、[查询覆盖](../API-COVERAGE.zh-CN.md)、
[导出](../SEARCH-EXPORT.zh-CN.md)及[运维](../RELEASE.zh-CN.md)。
源码与私有 workspace 分离，快照仍由使用者获取。

## 稳定性范围

保留候选版全量、混合负载与搜索恢复证据。
稳定包检查及证据边界见[验证记录](../VALIDATION.zh-CN.md)。
本次收敛不认证独立 ClickHouse 灾备，也不宣称已解决历史存储错误根因。
高并发和宽泛过滤的延迟限制继续明确保留。

目标是可用的本地服务。完整官方 API 对齐、全学科文本索引、PDF 下载、
自动版本合并、语义检索和快照同步都是后续可选工作，不作为使用 v0.3.0 的前提。
