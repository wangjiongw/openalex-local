# OpenAlex Local v0.3.1

[中文](v0.3.1.zh-CN.md) · [Documentation](../INDEX.md)

Optional keyless internal operation, with authentication still enabled by default.
Set the boolean `auth_required` to false in existing workspace configuration;
retain keys for re-enabling later. The web UI connects without a key and supports
query/export/download workflows. Status, capabilities and OpenAPI report the mode.

Request deadlines, upload limits and configured resource controls remain active;
anonymous rate accounting does not trust supplied key headers. No query semantics,
search projections, engine versions or data layouts change. Reuse existing indexes.
See [deployment](../QUICKSTART.md#optional-keyless-internal-deployment).

Tests cover both authentication modes, malformed settings, request guards and
export routing. Existing metadata/search recovery evidence remains scoped to its
original runs; this patch does not add independent database disaster recovery.
