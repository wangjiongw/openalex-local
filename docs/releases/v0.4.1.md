# v0.4.1 — M2 small entity directories

[中文](v0.4.1.zh-CN.md) · [Directory guide](../DIRECTORIES.md)

Adds imported small-vocabulary name browsing through both API contracts, independent of text indexes. The webpage adds domain/field/subfield hierarchy selection, country/license/language suggestions, saved hierarchy URLs and directory-to-work navigation. Work queries and exports reuse the existing filters and published indexes.

Directory matching is a case-insensitive literal display-name substring. Directory coverage is the imported source; work navigation remains limited to published search coverage. Publisher/funder/award catalog expansion is the next M2 batch. M0/M1 arXiv behavior is retained; source metadata contains no bibliography, and confirmed publication references stay source-specific.

Qualification covers directory counts/parents/cursor binding, metadata-only operation, existing search/arXiv/export regressions, native metadata and Earth profiles, synthetic responsive browser checks and installed-package query/web/export checks. Each installation must verify its own source coverage, readiness and exported files. These checks do not establish cross-Pod availability or high-concurrency capacity.

Upgrade API and export worker from the new package, retaining the previous environment and all persistent data. Existing OpenAlex and arXiv projection/signature files remain compatible; no source reimport or work reindex is needed. For software rollback, stop both services and start them from the previous installation. Preserve source/index pointers, parent segments, source snapshots, export jobs and private configuration.
