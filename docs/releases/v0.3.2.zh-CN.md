# OpenAlex Local v0.3.2

[English](v0.3.2.md) · [项目状态](../STATUS.zh-CN.md)

面向已支持本地检索流程的维护版本。网页将高级筛选、导出任务和仅支持元数据读取的
实体分类收拢，增加筛选重置／启用条件提示、导出勾选数量与实际服务版本。
引用关系区分源列表为空、请求失败和源／接口不一致，保留未解析目标，并说明预印本
缺少参考列表时仍可存在被引文献的原因。

API 查询语义、索引投影、引擎版本和数据布局不变；兼容的现有索引无需重建或重新发布。
内部免密访问保持可选，社区默认认证仍开启。

中英文项目状态、运维范围、路线图和验证说明同步到该基线。
合成浏览器检查覆盖响应式排版、引用状态与控件行为。实际文献覆盖与此前恢复证据
保留原有边界，不宣称独立数据库灾难恢复已经完成。
