# v0.6.0rc3：按字节限制候选查询

[English](v0.6.0rc3.md)

采样完成后，候选键列表过大可能超过 ClickHouse 默认 256 KiB 查询解析上限。
标题／作者倒排、目标特征、DOI 和父版本成员查询改为同时按行数和转义后的 UTF-8
字节数拆批，值列表不超过 128 KiB，并为 SQL 语法预留空间。
单个检索键超长时保留溢出待审状态，不错误标为未匹配；匹配规则和确认阈值不变。

验证：471 项单元测试通过，77 项按配置跳过，包括 Unicode、转义和大目标集合拆批
回归测试；隔离地学原生流程通过。使用新的不可变关联版本，复用兼容的完整特征和
已核验试点数据。现有已发布关联与 API 可继续使用；发布新关联数据前先升级至兼容软件。
