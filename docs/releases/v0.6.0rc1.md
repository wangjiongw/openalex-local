# v0.6.0rc1 — full-index version association candidate

[中文](v0.6.0rc1.zh-CN.md)

Adds an optional resumable workflow over existing published work indexes, with
thin ClickHouse features, bounded title/author/year candidates, independent review
packages, cumulative stratum batches and publication-anchor verification.
Schema-aware readers preserve v0.5 relationship releases. API/web expose pending
evidence separately; ordinary search, references and exports keep record semantics.

Validation: 468 unit tests passed (77 opt-in skipped), isolated Earth native
workflow passed, synthetic desktop/mobile browser acceptance passed, and all 90
packaged files verified against source and installed wheel. These checks do not
establish full-data completion, independent-label precision or cross-Pod capacity.

This is a candidate, not a replacement for the stable v0.5.0 release. Novel
bibliographic associations require independent calibration before confirmation.
