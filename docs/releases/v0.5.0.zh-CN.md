# v0.5.0 — OpenAlex 保守版本关联详情

[English](v0.5.0.md) · [版本关联流程](../VERSIONS.zh-CN.md)

新增独立、可恢复的关系 release，重放已发布 arXiv 精确证据，并进行固定 10 万条地学分层试跑。发表版冲突、更正与撤稿关系保留待审；重复 DOI、链接和标题相似均不自动确认。只有预印本时不虚构发表版。

新增版本组 API、可选模块就绪与覆盖统计、关联证据、发表版优先详情、手动版本选择和版本组 JSON 下载。保留全部原始 W ID，参考文献、OA 和被引数仍属于各自版本。既有 arXiv `/versions`、搜索计数／分页、勾选及查询导出契约不变；分组搜索和后台分组导出仍待后续。

验收包括合成规则、冲突、重放、抽样测试，原生元数据／地学集成，浏览器版本切换及引用归属，以及安装包验收。各安装仍须独立核验来源和关系数据后发布。这些验收不证明全部地学版本已关联、模糊匹配精度已校准、跨 Pod 容量达标，也不代表历史元数据校验故障根因已关闭。

无需重建文献或 arXiv 文本索引。API 和导出 worker 一同升级，保留旧环境、全部来源／索引依赖、关系暂存及指针历史。软件与关系数据分别回滚。
