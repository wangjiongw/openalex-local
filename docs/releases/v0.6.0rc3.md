# v0.6.0rc3 — byte-bounded candidate lookups

[中文](v0.6.0rc3.zh-CN.md)

Large candidate-key lists could exceed ClickHouse's default 256 KiB query parser
limit after sampling completed. Split postings, feature, DOI and parent-member
lookups by both row count and escaped UTF-8 bytes, reserving room for SQL syntax.
Each value list stays within 128 KiB; individual oversized retrieval keys preserve
overflow review rather than producing a false unmatched result. Matching rules
and confirmation thresholds are unchanged.

Validation: 471 unit tests passed (77 opt-in skipped), including Unicode/escaping
and large-set batching regressions; the isolated Earth native workflow passed.
Use a new immutable relationship release and reuse compatible completed features
and verified samples. Existing published relationships and API deployments remain
available. Upgrade to compatible software before publishing new relationship data.
