# OpenAlex Local v0.3.2

[中文](v0.3.2.zh-CN.md) · [Project status](../STATUS.md)

A maintenance release for the supported local retrieval service. The compact web
workspace groups advanced filters, export jobs and metadata-only entity types.
It adds filter reset/active-condition hints, export selection counts and a live
service version. Relations distinguish source-empty lists, request failures and
source/API inconsistencies, retain unresolved targets and explain why a preprint
can have incoming citations without its own reference list.

API query semantics, index projections, engine versions and data layouts are
unchanged. Compatible existing indexes need no rebuild or republication. Internal
keyless access remains optional; community authentication stays enabled by default.

The bilingual project status, operating scope, roadmap and validation notes align
around this baseline. Synthetic browser checks cover responsive layouts and
relation/control states. Corpus-specific coverage and previous recovery evidence
retain their original limits; no independent database disaster recovery is claimed.
