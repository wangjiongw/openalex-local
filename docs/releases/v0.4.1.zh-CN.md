# v0.4.1 — M2 小型实体目录

[English](v0.4.1.md) · [目录使用说明](../DIRECTORIES.zh-CN.md)

两种 API 契约新增已导入小型词表的名称浏览，不依赖文本索引。网页增加 domain／field／subfield 层级选择、国家／许可／语言候选、保存学科 URL 和目录到文献导航。文献查询与导出复用现有过滤和已发布索引。

目录按显示名称做不区分大小写的字面子串匹配。目录覆盖已导入来源，文献导航仍受已发布检索范围约束。出版商／资助方／项目目录扩展为 M2 下一批。保留 M0/M1 arXiv 行为：来源元数据不含参考列表，已确认发表版的书目保持自己的出处。

验收覆盖目录计数／父级／游标绑定、仅元数据模式、现有搜索／arXiv／导出回归、真实引擎 metadata 与地学 profile、合成响应式浏览器检查，以及安装包的真实查询／网页／导出。每个部署仍需验证自己的来源覆盖、就绪状态和导出文件。这些检查不能代替跨 Pod 或高并发容量验收。

用新包升级 API 和导出 worker，保留旧环境和全部持久数据。OpenAlex 与 arXiv 投影／签名文件保持兼容，无需重新导入来源或重建作品索引。回滚软件时停止两项服务，再从旧安装启动。保留来源／索引指针、父段、来源快照、导出任务和私有配置。
