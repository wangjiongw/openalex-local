# v0.6.0rc2 — bounded pilot sampling

[中文](v0.6.0rc2.zh-CN.md)

Full-corpus pilot selection could exceed the query memory limit because complete
feature payloads were sorted along with IDs. Rank IDs only under an 8 GiB,
two-thread limit, persist their count/checksum, then hydrate and verify bounded
batches with resumable checkpoints. Sampling seed, candidate rules and
confirmation thresholds are unchanged. Reuse compatible completed features in a
new immutable relationship release; retain failed release evidence.

Validation: 469 unit tests passed, 77 opt-in tests skipped; the isolated Earth
native workflow passed. A read-only full-corpus ID selection completed within the
explicit memory bound. Candidate matching and independent review remain separate
completion gates. Existing published relationships and API deployments need no
change to run the offline recovery. Upgrade to compatible software before
publishing a relationship release created by this version.
