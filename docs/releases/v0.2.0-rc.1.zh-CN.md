# OpenAlex Local v0.2.0-rc.1

[English](v0.2.0-rc.1.md) · [文档导航](../INDEX.zh-CN.md)

本候选版冻结面向用户已下载 OpenAlex JSONL 的原生工具链：本地校验、可恢复元数据／引用处理、
可选地学集合与 Manticore 索引，以及 CLI／API／网页部署。

Git 标签为 `v0.2.0-rc.1`；包与应用版本为 `0.2.0rc1`。

## 包含功能

- 新旧 JSONL 清单读取，保留源记录和字段。
- 默认纯元数据导入、标识符映射、引用审计与发布。
- 可选地学 profile，支持集合导出、索引文本／过滤、不可变快照及显式验收／发布。
- Workspace 与代码分离，固定原生引擎、离线缓存，支持 Linux x86_64／ARM64，并注明旧 ARM 兼容 profile。
- DOI／ID 与批量查询、参考／被引／相关文献展开、索引标题／摘要／作者姓名查询、受支持过滤及本地网页。
- 受控只读接入与搜索恢复工具。
- 修复 Manticore 快照在带点父目录下的导入。

## 升级与安装

在虚拟环境安装带标签源码或附件 wheel，使用 `SHA256SUMS.txt` 校验。
数据、私有配置和引擎二进制不打包。参见[部署指南](../QUICKSTART.zh-CN.md)和[发布运维](../RELEASE.zh-CN.md)。

快照由使用者获取，项目没有快照下载器。默认 profile 为 `metadata`；
已有地学计划必须显式传 `--profile earth_sciences`，可选引擎使用 `engines ensure --search`。
本次冻结不改变查询语义或索引布局。

## 验证与边界

374 项单元测试通过，76 项可选／live 跳过。Linux x86_64／ARM64 的原生单元／构建及元数据／地学链路通过。
安装 wheel 在源码外使用注明的 ARMv8 profile 通过。
既有数据本机 784 项、另一 Pod 784 项通过。1／8 并发各 60 秒短测零错误，
8 并发 P95 1.379 秒、P99 1.910 秒。网页搜索、过滤、关系标签、JSON 下载和布局通过。

完成的检查及范围见[验证证据](../VALIDATION.zh-CN.md)。
保留内部已发布索引及此前全量搜索恢复证据；此候选版未重建生产索引，也未替换内部服务。

这是预发布版，不完全对齐官方 API。全学科文本、PDF／TEI 下载、Parquet 导入、实时同步／删除／合并 ID、
自动版本归组、语义检索和 SDK／MCP 为后续工作。
搜索恢复不是独立 ClickHouse 灾备。源摘要或引用可能缺失；不宣称内部历史存储错误已修复。
