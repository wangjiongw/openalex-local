# v0.4.0 — 可选 arXiv 来源与已确认版本关联

[English](v0.4.0.md) · [运维说明](../RELEASE.zh-CN.md)

本版在现有 OpenAlex 快照服务上增加独立可选的 arXiv 工作流。使用者自行下载 Kaggle JSONL 元数据文件并配置本地路径，再按可恢复的规范化 → 关联 → 存储 → 索引 → 验收 → 发布流程处理。快照获取、来源数据和索引均不进入 Git。

默认筛选 2010 年及以后首次提交的全部 arXiv 学科。原始 JSON、未知字段、日期、作者、摘要、分类、许可及明确提供的发表 DOI 均保留出处。可选只读 DuckDB 二次库适配器会明确说明无法恢复的原始字段。

全部入选记录（包括未匹配预印本）均可独立文本检索、分页和导出。API 和网页显式切换来源，不混合计数与排序。唯一精确 DOI 证据可关联仍然独立的 OpenAlex 预印本／发表版，并在详情中优先展示已确认发表版；歧义与未匹配记录保持独立。

arXiv 元数据不提供参考文献列表。关联发表版的参考文献仍属于该发表版，不写入 arXiv 原始数据。在线同步、Crossref 增补、PDF 下载和混合来源排序继续后置。

安装 wheel 或带标签的源码，保留旧环境，再用新安装重启 API 和导出 worker。兼容的 OpenAlex 元数据与索引继续复用。arXiv 来源需单独构建并显式发布，升级软件不会自动发布数据。检查 `/status`、`/capabilities`、来源查询和导出。回滚软件时停止 API／worker，再从旧环境启动两者；保留新来源指针和文件用于恢复，或显式恢复保存的上一来源指针。不要删除任一来源版本或导出依赖。

软件单元／原生引擎／浏览器检查，与部署者自己的全量来源核对、持久索引检查、独立恢复、查询／导出验收分别记录。每个安装都须验收自己的输入和部署；本版不附带数据集或机器专属验收记录。
