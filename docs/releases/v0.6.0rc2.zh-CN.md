# v0.6.0rc2：限制试点采样内存

[English](v0.6.0rc2.md)

原试点采样将完整特征内容与 ID 一起排序，可能触发单查询内存上限。
改为仅排序 ID，限制查询为 8 GiB、两个线程，保存所选 ID 数量和校验值；
随后分批读取、回读核验特征并保存可恢复检查点。采样种子、候选规则和确认阈值均不变。
通过新的不可变关联版本复用已完成的兼容特征，保留旧失败记录。

验证：469 项单元测试通过，77 项按配置跳过，隔离地学原生流程通过。
全库只读 ID 采样已在指定内存限制下完成。候选匹配和独立审核仍分别验收。
后台恢复无需改变已发布关系或当前 API 部署；发布本版本生成的关联数据前，
先升级至兼容软件。
