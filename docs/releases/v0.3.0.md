# OpenAlex Local v0.3.0

[中文](v0.3.0.zh-CN.md) · [Documentation](../INDEX.md)

Stable local literature retrieval from a user-downloaded OpenAlex snapshot.
This release promotes the qualified v0.3.0-rc.1 application with no query,
projection, data-layout, engine or dependency changes; only the package/API
version declaration changes. Existing compatible metadata and search indexes
can be reused without rebuilding or republishing them.

## Supported workflow

- Read/verify local JSONL, preserve complete metadata/identifiers and citation edges.
- Serve DOI/ID lookup, records, references/citations/related works through HTTP and web.
- Optionally publish the Earth text profile and linked-author/institution catalogs;
  search titles, abstracts, keywords and author names with supported filters.
- Export queries or DOI/ID lists as JSONL.gz/CSV/DOI/ID files with durable jobs,
  cancellation, recovery and authenticated downloads through API/CLI/web.

Use [deployment](../QUICKSTART.md), [coverage](../API-COVERAGE.md),
[exports](../SEARCH-EXPORT.md) and [operations](../RELEASE.md). Source and private
workspaces are separate. Snapshot acquisition remains user-managed.

## Stability scope

Existing candidate full-data, mixed-load and search-recovery evidence is retained.
Stable-package verification and its evidence boundaries are recorded in
[validation](../VALIDATION.md). Promotion does not certify independent ClickHouse
disaster recovery or close historical storage-error root causes. High-concurrency
and wide-filter latency limits remain documented.

The goal is a usable local service. Complete official API parity, all-discipline
text indexes, PDF downloads, automatic version merging, semantics and snapshot
synchronization are optional future work, not prerequisites for using v0.3.0.
