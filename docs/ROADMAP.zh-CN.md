# 稳定版交付与维护

[English](ROADMAP.md) · [文档导航](INDEX.zh-CN.md)

当前稳定版为 **v0.5.0**。M0/M1 已交付可选 arXiv 来源及精确版本关联；M2 首批已交付小型元数据目录与文献导航。继续复用已有索引，详见[项目状态](STATUS.zh-CN.md)。

## v0.3.0：可直接使用的本地检索

发布目标是基于用户已下载快照，提供实用、稳定的 API，以及网页、CLI 和持久导出。
默认元数据／引用链路及可选地学检索方案已交付。兼容索引直接复用；
v0.3.0 不重建论文索引，也不改变已验收 v0.3.0-rc.1 的查询语义。

参见[功能清单](FEATURES.zh-CN.md)、[检索与导出](SEARCH-EXPORT.zh-CN.md)、
[验证](VALIDATION.zh-CN.md)及[运维](RELEASE.zh-CN.md)。
源码发布、数据发布和服务部署分别处理，不设置固定 24 小时等待。

## 后续维护优先级

- 修复已支持的查询、检索、引用和导出中可复现的问题。
- 保持兼容性、恢复能力、明确的 capabilities 和已有数据。
- 维护回归样例，测量实际本地负载；宽泛过滤影响使用时再针对性优化，避免增加用不到的功能。
- 保留恢复源并完善独立备份。既有搜索恢复证据不等于 ClickHouse 灾备认证。

扩大官方 API 对齐范围不作为发布要求。当前已支持路由及注明的覆盖／限制构成兼容契约。

## 已确定的后续方向

M0/M1 已在 v0.4.0 交付来源出处、精确 DOI 关联、独立 arXiv 检索与导出；M2 小目录和层级导航已在 v0.4.1 交付。见 [arXiv 工作流](ARXIV.zh-CN.md)和[目录说明](DIRECTORIES.zh-CN.md)。

版本详情交付后，M2 下一批为出版商／资助方名称目录及项目到文献关联。M3 处理可靠追更、删除与重定向；M4 扩展可配置的作品检索范围；M5 处理链接与内容下载。依赖和验收条件见[分阶段开发计划](NEXT-STEPS.zh-CN.md)，这些后续阶段不属于当前已实现能力。

Semantic Scholar 继续暂缓。Crossref REST／公开文件是 DOI／版本身份确认后的独立可选书目来源。大范围扩容先明确追更契约，PDF／TEI 获取保持后置。

## 可选扩展

PDF／TEI 下载、更广的非 DOI 版本关联与匹配校准、其他文本范围／实体名称、Parquet 输入、
快照更新／删除／合并 ID、语义检索、SDK 和 MCP 均为独立后续任务。
它们不阻塞本版本，也不要求替换当前引擎。外部 A/D 图谱写入仍不属于核心项目。
快照由用户获取；私有数据、引擎、凭据和输出保留在 Git 外。

保守版本关联详情已在 v0.5.0 交付，随后再补余下 M2 实体目录。见[版本关联流程](VERSIONS.zh-CN.md)；分组搜索仍留待后续。
