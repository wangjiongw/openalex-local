# 交付状态与后续工作

## 候选版 v0.3.0-rc.1

已实现本地快照读取、完整原始元数据与引用导入／审计、元数据 API／网页服务、可选地学集合和 Manticore 索引、原生安装与搜索恢复。
本版增加地学关联作者及全部已导入机构的实体目录、组合查询、持久论文导出和相应网页控件。
复用已有论文索引，身份到论文的候选映射加速必需的身份条件，同时保持原署名语义。

参见[功能清单](FEATURES.zh-CN.md)、[检索与导出](SEARCH-EXPORT.zh-CN.md)、[验证](VALIDATION.zh-CN.md)和[发布边界](RELEASE.zh-CN.md)。
快照仍由使用者自行获取。运行数据、引擎二进制、私有配置与导出保留在 Git 外。

## 候选版反馈与稳定版

修复候选范围内可复现的问题，维护兼容性和验证证据，再考虑发布 v0.3.0 稳定版。
不设固定 24 小时等待；发布 Git 标签也不会自动切换数据或服务。
每个 workspace 需要显式构建、验收和发布。

## 后续可选工作

- 在检索／导出流程之后对接 PDF／TEI 下载。
- 增加实体名称索引、用户定义文本范围与更宽泛的过滤优化。
- 经过校准的书目匹配和跨记录版本关联。
- Parquet 输入、新快照更新，以及删除／合并 ID 的应用。
- 独立 ClickHouse 灾备、语义检索、SDK 和 MCP。

这些扩展不是使用当前候选版的前提。官方风格路由不代表完全对齐实时 OpenAlex API。
外部 A/D 图谱写入仍属于独立项目。
