**稳定基线：v0.3.2。** 已支持的本地检索流程进入维护阶段。
实际部署版本和覆盖范围以服务 `/status`、`/capabilities` 及网页页脚为准；

## 已交付流程

| 阶段 | 已提供能力 | 边界 |
| --- | --- | --- |
| 快照输入 | 下载／格式指引、配置本地路径、清单与校验 | 使用者自行下载一致快照，不自动下载 |
| 元数据 | ClickHouse 可恢复导入、完整源 JSON、标识符与引用关系 | 保留原始输入，源缺失字段保持缺失 |
| 可选检索 | 地学示例、Manticore 构建／验收／发布、实体目录 | 仅已发布范围与字段可搜索；地学是示例，不是项目学科限制 |
| API 与 CLI | DOI／ID、词法文本、已支持的组合过滤和引用展开 | 以已支持路由为契约，不承诺完整官方 API 对齐 |
| 网页 | 紧凑检索、常用／高级筛选、重置及条件提示、结果勾选／导出数量、桌面／移动详情 | 预印本仍是独立记录，明确提示源数据覆盖 |
| 导出 | API／CLI／网页的 JSONL.gz／CSV／DOI／ID、固定版本任务、取消／恢复和下载 | 不自动下载 PDF，也不自动导出所有引用目标的完整记录 |
| 运维 | 原生 Linux x86_64／ARM64 包、workspace 单一写入者、持久产物、显式检查与回滚指引 | 源码／软件包发布、数据发布和服务升级分别进行 |

## 日常使用中需明确的限制

- 全量元数据导入与文本搜索覆盖不同。未进入文本索引的文献仍可通过 DOI／ID 定位，
  也可能作为引用目标展开。
- `referenced_works` 为空表示快照未记录结构化参考列表，不代表原文没有参考文献。
  本文缺少参考列表，仍可被其他论文引用。预印本的覆盖可能不完整，不能概括为所有
  arXiv 记录都没有正向参考关系。
- 预印本与正式发表版本不自动关联、合并或作为同一论文重新排序；可使用发表 DOI／标题
  查看对应记录自己的数据。
- 未解析目标、缺失摘要和 DOI 歧义保持显式状态。
- 当前搜索恢复证据不证明独立 ClickHouse 灾难恢复能力。网页／软件维护发布不宣称
  历史存储与校验故障已经定位根因。
- 社区部署默认要求 API key。内部部署可显式关闭认证，范围包括导出管理和下载。

已选定的后续顺序见[下一阶段开发计划](NEXT-STEPS.zh-CN.md)；下述新增能力在单独验收和发布前仍未实现。

Semantic Scholar 不在当前选定范围；Crossref API／公开文件增补属于后续可选来源，v0.3.2 尚未实现也不依赖它。
